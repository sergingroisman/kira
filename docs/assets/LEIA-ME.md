# docs/assets/ — prints de design (Kombai)

Os três prints de referência do dashboard/TUI devem viver aqui com estes nomes
(exatamente como referenciados no `README.md`, seção "Design de referência"):

| Arquivo | Conteúdo do print |
|---|---|
| `design-dashboard-achados.png` | Dashboard amarelo-coral: resumo, tabela de achados com sparkline, detalhe lateral, tendência, armazenamento, duração das sessões, documentos |
| `design-wiki-breadcrumbs.png` | Modo wiki com breadcrumbs e detalhe da página (Causa / Caminho de correção / Verificação / Achados / Arquitetura) |
| `design-wiki-thread.png` | Wiki thread única com comentários laterais, votação e publicação de resposta |

**Por que os arquivos ainda não estão aqui**: os prints chegaram à sessão de
auditoria como imagens de conversa, não como arquivos no disco — agente não
materializa binário do ar. Salve os três PNGs exportados do Kombai com os nomes
acima e o README passa a renderizá-los sem nenhuma outra mudança.

Fontes conhecidas dos designs: `.kombai/canvas/kira-fluxo-wireframes.canvas`,
`.kombai/canvas/kira-cyberpunk.canvas` e `.kombai/canvas/kira-fluxo-cli.canvas`.
